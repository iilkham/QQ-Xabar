# QQ-Xabar

Новостной веб-сайт, посвящённый новостям Каракалпакстана.

## О проекте

QQ-Xabar — современный новостной сайт с категориями новостей, отдельными страницами публикаций и административной панелью.

## Функционал

- Главная страница с последними новостями
- Страница всех новостей
- Детальная страница новости
- Категории новостей
- Страница «О нас»
- Контактная страница
- Административная панель
- Адаптивный дизайн
- Изображения для новостных материалов

## Технологии

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git / GitHub
