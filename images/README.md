# Ваши изображения

Поместите свои файлы в эту папку, сохранив следующие имена:

- `main-news.jpg` — большая главная новость.
- `side-news-1.jpg`, `side-news-2.jpg`, `side-news-3.jpg` — три небольшие новости рядом с главной.
- `news-1.jpg` — `news-6.jpg` — шесть карточек раздела «Новости».
- `popular-feature.jpg` — большая карточка раздела «Популярное».
- `discussed-1.jpg` — `discussed-4.jpg` — блок «Самое обсуждаемое».

Можно использовать PNG или WebP. В таком случае измените расширение соответствующего пути в `../index.html`.
